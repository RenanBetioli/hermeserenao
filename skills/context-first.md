# Context first

1. Leia `context/index.md`.
2. Siga o `index.md` do domínio relevante.
3. Responda com o trecho e o caminho do arquivo de origem.
4. Se a informação não existir na base, diga que não existe.

Esta skill é executada pelo núcleo quando há um agente real conectado. No modo local, a busca determinística de `/api/ask` cumpre o mesmo papel de rastreabilidade.
