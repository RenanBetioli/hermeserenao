# Memória e base de contexto

A memória persistente guarda apenas fatos compactos e duráveis: preferências do operador, caminhos canônicos e limites de permissão. Textos longos, procedimentos e decisões ficam em arquivos Markdown versionados na base de contexto.

Regra prática: se a informação precisa de mais de duas linhas para ser explicada, ela pertence à base de contexto, não à memória. A base é navegada por índices; a memória é carregada inteira a cada sessão.

Nunca coloque segredos em nenhuma das duas. Para dados sensíveis, use um cofre externo e registre apenas o caminho de referência, nunca o valor.
